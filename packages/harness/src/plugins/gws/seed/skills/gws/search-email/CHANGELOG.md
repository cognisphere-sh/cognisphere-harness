## 1.0.0

- Initial version: Gmail query syntax and how to narrow a search, the
  search-then-read workflow, the two standing searches (`in:sent newer_than:1d`,
  `is:unread in:inbox`), filing with `email labels` / `email label`
  (`--add`/`--remove`/`--create`/`--archive`/`--read`/`--thread`), what filing
  does to which mail wakes the agent, and server-side Gmail filters via
  `gws gmail users settings filters`.
