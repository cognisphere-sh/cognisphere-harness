# create-skill — changelog

## 1.3.0

- "What's included" is now a brief sketch of the main procedures, not an
  exhaustive contents list; partial applicability moved under "when to use
  it" as a trigger shape; whole description kept under 1000 characters.

## 1.2.0

- Description gained the situational triggers (a procedure written down for
  reuse, re-derived a second time, or found inlined in a prompt file /
  knowledge/) alongside the literal phrases.

## 1.1.0

- Description spec expanded to four required parts: summary, what's included
  (procedures/topics/scripts/artifacts — so an agent can spot a partially
  relevant skill), when to use, and version; metadata carries author +
  version.

## 1.0.0

- Initial version: author/update a versioned agent skill (SKILL.md +
  changelog + scripts/ + artifacts/), including migrating procedures out of
  prompt files and knowledge/SOPs.
